# Contributing

Flashlights is published for use and study, and does not take code
contributions: pull requests are closed without being merged.

Bug reports and ideas are welcome as
[issues](https://github.com/mariatta/flashlights/issues). A suggestion may be
implemented, but code from a pull request is not copied into Flashlights.
Report security problems privately, as described in [SECURITY.md](SECURITY.md).

You are free to run and change Flashlights under its licence (see
[LICENSE](LICENSE)). The [developer guide](docs/developer/contributing.md)
covers running the tests and the linters on your own copy.
